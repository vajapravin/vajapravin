## 🚀 Featured AI Projects

### 🛍️ [Trove — Agentic E-Commerce Recommendations](https://github.com/vajapravin/trove-ecommerce-recommendation)

An agentic recommendation platform designed to use browsing behaviour and product information to provide more relevant recommendations.

- LangGraph workflow for behavioural analysis, retrieval, evaluation, refinement, and ranking.
- Semantic retrieval using ChromaDB to ground recommendations in a product catalogue.
- Candidate shortlisting followed by ranking.
- FastAPI backend and supporting data and observability tooling.

**Technologies:** `Python` `LangGraph` `FastAPI` `RAG` `ChromaDB` `SQLite` `Docker` `LangSmith`

[Repository](https://github.com/vajapravin/trove-ecommerce-recommendation) · [Live Demo](https://trove-ecommerce-recommendation.vajapravin.me)

### 🏥 [Agentic Healthcare](https://github.com/vajapravin/agentic-healthcare)

A stateful multi-agent application for healthcare administration workflows, including patient interactions and appointment operations.

- LangGraph coordination between supervisor and specialist agents.
- Stateful conversations and tool-driven operations.
- API endpoints and persistent data.
- Local PII redaction using Microsoft Presidio.

**Technologies:** `Python` `LangGraph` `FastAPI` `PostgreSQL` `SQLAlchemy` `Presidio` `Docker`

[Explore the repository](https://github.com/vajapravin/agentic-healthcare)

### 📊 [Customer Churn Prediction](https://github.com/vajapravin/random-forest-predicting-customer-churn)

A supervised machine learning project exploring customer churn prediction for a subscription-based streaming service.

**Focus:** `Python` `Machine Learning` `Random Forest` `Classification` `Customer Analytics`
